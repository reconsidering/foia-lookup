# State directory coverage

The directory grew from 300 to 1,058 entries across all 50 states and D.C., adding 758 departments, subagencies, boards, and authorities. This is a curated directory, not an exhaustive roster of every public body, local office, university, or licensing board.

## Sources and contact availability

New entries carry an official `sourceUrl` and a `sourceChecked` date of 2026-10-15. The date records when the reference was checked, including indexed official-page results when a page could not be opened directly; it is not a guarantee of current contact availability. An agency directory can establish the agency's existence without establishing a records-request contact. Those entries explicitly say that this directory has no verified records email or phone and link to the official source for follow-up. They do not assert that the agency publishes no contact information anywhere.

Illinois, Maine, and Wisconsin publish statewide records-contact lists; their listed contacts were incorporated, including existing entries where the official list supplied a current contact. Other request channels were taken from agency request instructions, policies, forms, and state request selectors. Agency-specific searches were also made for the 555 additions that initially had no verified email, phone, or request link. Search results pointing to another agency, federal offices, appeals bodies, or general inquiry addresses were not treated as request mailboxes.

`emails` contains request contacts for the copyable lists. Some records officers are named individuals because the official source designates them. Inquiry-only or accessibility-fallback addresses appear in notes instead. A `portal` can link to a request portal, an agency request form, or instructions, distinguished by `portalLabel`. “Portal only” is used only where the source requires it (for example, Alabama education); a recommended online method does not establish exclusivity. PDFs are linked as official sources, not called portals.

## Maintenance

For a new agency, verify its name against an official state directory or its own website. Add a request address only when the official source associates it with the requested agency and records type. Keep general questions, records-status inquiries, appeals, and restricted personal-record workflows separate from general request mailboxes. If the source only supplies a form or portal, leave `emails` empty, link the form or portal, and explain its scope. Record the official source and check date. Do not substitute a federal FOIA portal for a state records process.

Legacy entries without a source/check date were not reverified by this expansion. Statute metadata also remains a separate, unverified summary.
